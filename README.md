# 🏃‍♂️ Türkiye Koşu Takvimi 2026

## Türkiye'nin En Kapsamlı Yol ve Trail Koşu Takvimi

Bu proje, 2026 yılında Türkiye genelinde düzenlenecek **tüm yol koşuları** ve **trail yarışlarını** tek bir platformda toplayan modern, kullanıcı dostu bir web uygulamasıdır.

## ✨ Özellikler

### 🎯 Temel Özellikler
- **80+ Yarış**: Ocak'tan Aralık'a kadar tüm yarışlar
- **50+ Şehir**: Türkiye'nin her köşesinden etkinlikler

- **Gerçek Zamanlı Filtreleme**: Anında sonuç gösterimi

## 🚀 Kullanım

1. `index.html` dosyasını çift tıklayarak tarayıcınızda açın
2. Veya bir web sunucusu kullanın (önerilen)

### Yerel Web Sunucusu (Önerilen)
```bash
# Python ile
python3 -m http.server 8000

# Node.js ile
npx http-server

# Daha sonra tarayıcınızda açın:
http://localhost:8000
```

## 💡 Antrenör Tavsiyeleri

### Yol Koşuları İçin
- ✅ Düz parkurlarda tempo koşuları
- ✅ Interval antrenmanları
- ✅ Haftalık 4-5 antrenman
- ✅ Pace kontrolü
- ✅ Asfalt zeminlere uygun ayakkabı

### Trail Koşuları İçin
- ✅ Dağ/tepe antrenmanları
- ✅ Teknik iniş-çıkış pratiği
- ✅ Kuvvet antrenmanları (bacak-core)
- ✅ Navigasyon becerisi
- ✅ Trail ayakkabısı

### Planlama Önerileri
- 📅 Hedef yarışınızı 3-4 ay önceden belirleyin
- 📈 Küçük mesafelerden başlayıp büyüterek ilerleyin
- 🎯 Yılda 4-6 yarış hedefleyin
- 💤 Yarışlar arası dinlenme planlayın
- 💰 Erken kayıt avantajlarından yararlanın

## 🤝 Katkıda Bulunma

Bu proje sürekli güncellenmektedir. Yeni yarış eklemek veya bilgi güncellemesi yapmak için:

1. Yarış bilgilerini `races-data.js` dosyasına ekleyin
2. Aşağıdaki formatta veri girin:
```javascript
{
    name: "Yarış Adı",
    type: "yol" veya "trail",
    date: "2026-MM-DD",
    city: "Şehir",
    distances: ["5K", "10K", "21K"],
    status: "open", "waitlist", veya "closed",
    highlights: ["Özellik1", "Özellik2"]
}
```
